# 📖 Project Overview

A luxury hotel aims to understand which guest segments generate the most ancillary revenue from services such as:

- Spa
- Dining
- Activities

Leadership observed significant differences in guest spending but lacked clear insights into:

- Which customer segments contribute the most revenue
- Which marketing opportunities are being missed
- How ancillary revenue can be increased

As the assigned Data Analyst, the objective is to clean and validate multiple datasets, perform exploratory data analysis (EDA), identify high-value customer segments, and provide actionable business recommendations.

---

# 🎯 Business Problem

The leadership team wants answers to the following question:

> **Which guest segments generate the highest ancillary revenue, and what actions should the hotel take to maximize this revenue?**

---

# 📊 Objectives

This project aims to:

- Validate and clean multiple datasets
- Explore customer behavior
- Analyze ancillary spending patterns
- Identify high-value guest segments
- Develop meaningful business metrics (KPIs)
- Generate actionable business recommendations
- Present findings to executive leadership

---

# 🗂 Dataset

The project combines data from three independent hotel systems.

| Dataset | Description |
|----------|-------------|
| Guest Profiles | Guest loyalty tier and marketing consent |
| Stay Details | Stay information, booking channel, guest count, reason for stay |
| Ancillary Spend | Individual ancillary purchases made by guests |

Because the datasets originate from different operational systems, inconsistencies and missing values are expected and must be addressed before analysis.

---

# 🧹 Data Validation & Cleaning

The following validation steps were performed:

- Checked missing values
- Removed duplicate records
- Validated guest IDs
- Corrected data types
- Standardized categorical values
- Identified inconsistent records
- Checked for impossible values
- Validated relationships across datasets
